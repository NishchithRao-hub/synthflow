# Screenshots and Demos

Use this checklist to maintain polished, consistent visual documentation for README, docs, and portfolio pages.

## Required Screenshots

1. Landing/dashboard overview
2. Workflow builder with node palette
3. Node configuration side panel
4. Execution run monitor in progress
5. Execution run details on success/failure
6. Billing/usage dashboard
7. Settings page (API keys + account)
8. API docs page (Swagger)

## Required GIFs

1. Build and run a workflow end to end
2. Trigger webhook and watch real-time updates
3. Upgrade flow or billing portal walkthrough

## Recommended Capture Specs

- Format: PNG for screenshots, GIF/MP4 for demos
- Width: 1920px desktop captures preferred
- Theme: consistent light/dark choice across all captures
- Redact secrets, email addresses, and tokens
- Keep GIF length between 10s and 30s

## File Naming Convention

- dashboard-overview.png
- workflow-builder.png
- workflow-node-config.png
- run-monitor.png
- run-details.png
- billing-usage.png
- settings-api-keys.png
- api-swagger.png
- synthflow-demo.gif
- synthflow-webhook-realtime.gif
